> **日期**: 2026-05-30
> **作者**: Keenie 🐰
> **状态**: 设计稿 v1

---

## 一、概述

Keenran 的个人网络空间。一个**赛博绿码风**的单页应用，部署在 `keenran.top`，作为"数字客厅"展示 Keenran 的在线身份、作品、动态和日常。博客独立运行在 `blog.keenran.top`（Hexo + Butterfly），两者通过导航跳转连接。

### 核心定位

> 一个活的、有呼吸感的网络空间——不是冷冰冰的简历页，而是像走进 Keenran 的数字房间，到处是正在运行的窗口、跳动的数据、熟悉的音乐。

---

## 二、技术选型

| 层级 | 技术 | 说明 |
|------|------|------|
| **前端框架** | 原生 HTML/CSS/JS（或轻量框架 Preact/Svelte） | 单页应用，无路由依赖 |
| **部署** | GitHub Pages | 免费，支持自定义域名 `keenran.top` |
| **域名** | `keenran.top`（主站）/ `blog.keenran.top`（博客，待配置） | 通过 CNAME 解析到 GitHub Pages |
| **数据持久化** | localStorage | 播放器进度、主题偏好等 |
| **外部数据** | GitHub API / 网易云公开 API / 第三方 | 动态拉取最新内容 |

## 三、UI/UX 设计

### 3.1 设计语言

- **配色方案**：绿码黑客风格
  - 主背景：`#0a0a0f`（极深黑）
  - 文字/主色：`#00ff41`（经典绿码绿）
  - 辅色：`#00cc33` / `#39ff14`
  - 强调/高亮：`#00ff88`（偏青的亮绿）
  - 玻璃面板：`rgba(0, 255, 65, 0.05)` 毛玻璃 + `rgba(0, 255, 65, 0.2)` 发光边框
- **字体**：等宽/像素风格字体用于装饰性文字（如时钟、终端），可读性字体用于内容
- **动效**：慢呼吸光晕、扫描线效果（可选）、粒子浮动
- **背景**：深邃的深空黑渐变（`#0a0a0f` → `#050510`），模拟无垠太空的纵深感
- **代码漂浮**：页面背景中持续有代码字符（数字、符号、关键字）在空间中漂浮、游走、渐隐，营造数字世界的沉浸感

### 3.3 响应式设计

- **桌面**：小组件自由浮动/网格排列，宽屏体验最大化
- **平板**：调整为 2 列网格，小组件纵向堆叠
- **手机**：单列瀑布流，小组件全宽，播放器固定底部导航

## 四、小组件系统

所有小组件都是**可独立配置、可拖动（桌面端）**的模块单元。

### 4.1 🎵 网易云播放器

- **功能**：多歌单支持，有记忆的播放体验
- **逻辑**：
  - 预配多个歌单 ID
  - 首次访问 → 随机选歌单 → 随机选一首歌自动播放
  - 后续访问 → localStorage 读取上次歌单+歌曲+播放进度 → 继续播放
  - 用户可手动切换歌单（下拉选择）
  - 每次页面加载通过网易云 API 拉取最新数据
- **UI**：毛玻璃卡片，右下角悬浮固定

### 4.2 🕐 赛博时钟

- **功能**：实时时钟 + 动态问候
- **逻辑**：
  - 显示当前日期、星期、时分秒
  - 根据时间段切换问候语
  - 数字切换时有轻微发光闪烁
- **UI**：像素/等宽字体，左上角或顶部

### 4.3 📡 动态终端窗

- **功能**：模拟终端输出，展示实时动态
- **逻辑**：
  - 自动滚动输出预设数据（GitHub 动态、站点信息、彩蛋内容）
  - 真实数据源：GitHub API 拉取最新 Push/Star/Issue
  - 无数据时回退到预设的"黑客式"占位文本
- **UI**：半透明绿底黑字终端窗口

### 4.4 🎮 当前状态卡

- **功能**：展示 Keenran 最近的关注点
- **数据**：手动配置（可更新），暂不接入自动源
- **内容示例**：
  - "🎯 正在攻克：信息学算法"
  - "🎮 最近在玩：Minecraft"
  - "📖 在读：xxx"

### 4.5 🌐 社交导航环

- **功能**：聚合社交入口
- **内容**：
  - GitHub → `https://github.com/keenranlee`
  - B站 → `https://space.bilibili.com/541864556`
  - X/Twitter → `https://x.com/keenranlee`
  - TikTok → `https://tiktok.com/@keenranlee`
  - Telegram → `https://t.me/keenranlee`
- **UI**：圆形排列或网格图标，悬停发光

### 4.6 🥚 彩蛋们

- 鼠标快速连击某处触发隐藏效果
- 背景偶尔飘过一行绿码注释
- 深夜访问自动切换暗黑专属配色（或者绿码变暗紫？）
