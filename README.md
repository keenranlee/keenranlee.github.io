# Keenran CyberSpace 🌐

Keenran Lee 的个人网络空间 — 赛博绿码风的数字客厅。

## 简介

一个「活的、有呼吸感的网络空间」——不是冷冰冰的简历页，而是像走进数字房间，到处是正在运行的窗口、跳动的数据、熟悉的音乐。

### 技术栈

- **纯前端 SPA**：HTML5 + CSS3 + Vanilla JS
- **部署**：GitHub Pages（`keenran.top`）
- **数据持久化**：localStorage
- **外部 API**：网易云音乐公开 API、GitHub API

### 功能

- 🕐 实时桌面时钟
- >_ 模拟终端（支持命令互动）
- 🎵 网易云音乐播放器（多歌单切换）
- 📊 状态卡 + 社交链接
- 🌌 深邃深空背景 + 代码漂浮粒子
- 🚀 开机启动动画
- 🎮 隐藏彩蛋
